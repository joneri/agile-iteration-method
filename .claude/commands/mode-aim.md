# Set AIM Mode

Map this command to `/aim mode strict|auto` from
`docs/workflow/adapter-command-contract.md`.

Follow [runtime source routing](../../docs/workflow/adapter-command-contract.md#runtime-source-routing)
before selecting state. Validate `strict` or `auto` within the current
mandate. Native Stories have no mode-mutation helper: report that limit and do
not rewrite a frozen delivery policy. A session preference cannot approve or
amend an existing delivery. For explicitly selected legacy work, update only
that active Epic workspace's mode through its supported protocol. Changing mode
never approves a gate, grants owner authority or selects Ship/Loop.

If command-file routing is unavailable, state that limitation and handle the
same `/aim mode` intent in ordinary Claude chat.
