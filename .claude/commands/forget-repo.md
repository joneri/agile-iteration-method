# Forget AIM Repository Knowledge

Map the request to:

```text
/aim forget-repo <category> "<rule-id>"
```

Follow `docs/workflow/repo-awareness-calibration.md`.
Preserve the state effect from `docs/workflow/adapter-command-contract.md`.
Locate the structured shared or personal rule, show the proposed removal, persist the change to the owning profile, and update readiness or freshness when needed.
Never mutate `.aim/` to forget stable repository knowledge.

If command-file routing is unavailable, state that limitation and handle the
same `/aim forget-repo` intent in ordinary Claude chat.
