AIM 4.2
Behåll riktningen. För arbetet framåt.

Förslag till lanseringstext · AIM 4.2 · 12 oktober 2026.

AIM 4.2 ger AI-assisterad utveckling gemensamma regler för att fortsätta godkänt arbete mellan sessioner. Agenten kontrollerar vilka beslut och svar som fortfarande gäller för det aktuella uppdraget. Nödvändiga frågor visar ett rekommenderat alternativ först. Frågor som beror på andra svar väntar tills förutsättningarna är klara.

En valfri hjälpfunktion kontrollerar att svar hör till rätt fråga och avvisar inaktuella eller motstridiga svarskvitton. Den lagrar inga beslut. Samordnaren verifierar fortfarande källor och dokumenterar beslut; användaren accepterar leveransen.

Grunden är fortsatt människornas behov: Product Owner identifierar Epics och User Stories, en leverans kan samla Stories från olika Epics och oberoende granskning och validering knyter resultatet till acceptanskriterierna. AIM UI visar hur Stories rör sig genom processen.

För Codex, GitHub Copilot och Claude Code. AIM UI är fortsatt Beta. Ingen datamigrering krävs; uppdatera installerad skill och starta om sessionen. De syntetiska testerna ger inget stöd för generella löften om tids- eller tokenbesparingar.
