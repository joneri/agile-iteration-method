AIM 4.2
Keep the intent. Carry the work forward.

Suggested announcement copy · AIM 4.2 · 12 October 2026.

AIM 4.2 gives AI-assisted development a shared contract for continuing authorized work across sessions. Agents check which decisions and answers still apply to the current assignment. Necessary questions present a recommended option first, while dependent questions wait for the answers they need.

An optional stateless helper checks that replies belong to the right question and rejects stale or conflicting receipts. The coordinator still verifies sources and records decisions. User acceptance remains explicit.

The foundation stays focused on people: a Product Owner discovers Epics and User Stories, deliveries can combine Stories from different Epics, and independent review and validation connect the result to acceptance criteria. AIM UI shows Stories moving through that process.

Available for Codex, GitHub Copilot and Claude Code. AIM UI remains Beta. No data migration is required; update the installed skill and reload its session. No general speed or token-saving benefit is claimed from the synthetic tests.
